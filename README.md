FACSS CRM - Intranet Enterprise

Sistema de Gestão de Relacionamento com Clientes B2B, Ordens de Serviço e Inventário de Telemetria Operacional.

Funcionalidades Principais

Dashboard Geral: KPIs operacionais, gráficos de saúde da carteira e carga por analista.

Gestão B2B: Cadastro, fichas detalhadas do cliente, faturamento e histórico de interações.

Pipeline Kanban: Mapeamento visual da jornada comercial por etapas.

Ordens de Serviço (OS): Emissão, controle de criticidade, impressão formatada e notificação por e-mail.

Módulos & Rastreadores: Controle de estoque, placas vinculadas e situação de frota.

Tecnologias Utilizadas

Linguagem: Python 3.11

Framework Web: Flask

Persistência: Google Cloud Firestore

E-mail API: Brevo HTTP API

Estilização: Bootstrap 5 + CSS3 Custom Dark Theme
